# Provenance

Original Luce Base TLS 1.3 helpers, Copyright 2026 Dy Mokomi, MIT OR Apache-2.0.
HKDF-Expand-Label follows RFC 8446 section 7.1 using `luce-crypto` HKDF-SHA-256.
DNS hostname matching follows the exact/wildcard subset of RFC 6125.
The bounded TLS Certificate list and X.509 path checks follow RFC 8446 section
4.4.2 and the applicable RFC 5280 basic path, extension, key-usage and EKU rules.
The embedded ISRG Root X2 P-384 public key is transcribed from the official
certificate at https://letsencrypt.org/certs/isrg-root-x2.pem.

No OpenSSL, BoringSSL or other foreign TLS/X.509 engine is linked. The live
certificate bytes in the deterministic test were publicly served by the Lucia
OS Caddy endpoint on 2026-09-19 and remain certificate material, not third-party
code.

`src/luce_tls/roots.lucb` holds the subject names and public keys of root
certificates taken from Mozilla NSS `lib/ckfw/builtins/certdata.txt`
(https://hg.mozilla.org/projects/nss), distributed under the Mozilla Public
License 2.0; it is generated by `tools/mozilla_roots.py` and records the source
file's SHA-256. `tests/chains/` holds certificates served publicly by the named
mail servers, captured on 2026-10-02 as test fixtures.

## Reference test data

Test data only; no code from these projects is included. Each converter in
`tools/` regenerates its files from the named source and records the source's
SHA-256. All retrieved 2026-10-02.

- `tests/x509/bearssl/`: certificates, Names and cases from BearSSL
  `test/x509/` (https://www.bearssl.org/, revision
  7bea48e5e850ab4cafbe68d3765cdaba13a86d6f; MIT license, Copyright (c) 2016
  Thomas Pornin <pornin@bolet.org>), converted by `tools/bearssl_x509.py`;
  checksum in `tests/x509/bearssl/SOURCE-SHA256SUMS`.
- `tests/x509/openssl/`: DER forms of OpenSSL `test/certs/*.pem` and the cases
  of `test/recipes/25-test_verify.t`, and `tests/vectors/openssl_tls13_kdf.txt`
  from `test/recipes/30-test_evp_data/evpkdf_tls13_kdf.txt`
  (https://github.com/openssl/openssl, branch openssl-3.5, revision
  adb795d9b166b7342ad1227b6241f3d31d973438; Apache License 2.0, Copyright The
  OpenSSL Project Authors), converted by `tools/openssl_verify.py` and
  `tools/openssl_tls13_kdf.py`; checksums in
  `tests/x509/openssl/SOURCE-SHA256SUMS` and `tests/vectors/OPENSSL-SHA256SUMS`.
- `tests/vectors/rfc8448_1rtt.txt`: the section 3 trace of RFC 8448, "Example
  Handshake Traces for TLS 1.3" (https://www.rfc-editor.org/rfc/rfc8448.txt),
  IETF Trust test data used as test data, converted by
  `tools/rfc8448_vectors.py`; checksum in `tests/vectors/RFC8448-SHA256SUM`.
